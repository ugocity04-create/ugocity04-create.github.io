# My Portfolio

A one-page portfolio built with React and Vite.

## Edit your details
Open `src/data/site.js`. Change your name, WhatsApp number, email, projects, services and FAQs. Save and the site updates.

## Images (all optional, in `public/images/`)
- `shot-coil-crown.jpg`, `shot-hearth-key.jpg`, `shot-ember-pepper.jpg`: screenshots of each site
- `me.jpg`: your photo (square works best)

Missing images show a coloured placeholder.

## Run
```
npm install
npm run dev
```

## Deploy
Push to a GitHub repo named `<your-username>.github.io`, set Pages source to GitHub Actions.
